The files in this directory contain information about the various "design" decisions about the project
- `code-design.md` - the way the code is laid out in the directory, what code can do what, how the game state flows, etc
- `game-design.md` - information about the design of the game itself - what the different features are, how the interact, etc
- `decisions.md` - a dated log of design/architecture decisions: what was decided, when, and why
- `todo.md` - known work that still needs doing: fixes, cleanup, and follow-ups
